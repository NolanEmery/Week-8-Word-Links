# Week-8-Word-Links
Plan It:

What is the goal of this website?
To be a word game to compete with Wordle where the user needs to connect two words using other words.

Who are you building for, and what do they care about?
It is made for people who like to play word games that are fast and repeatable.

Describe how a player should use the website from the moment they visit it. What should they see first, what should they click, and what should happen next?
The user should see a 15x15 grid where each square is allowed to contain a letter. The user can click play to start and can click reset at any time.

How should the grid, word entry, and scoring work on the page?
The user plays a word by dragging it onto the grid and connecting it to an existing letter. The user gets 10 base points for each new word. Put the score on one side. The user wins when the two words connect.

How should the site look and feel to attract the same audience as Wordle?
It should look like a tabletop game, or something out of a newspaper.

Test It:

Add more word options to play. Make them similar letter counts. Make more places where the user can play a word. Allow the possibility to connect words horizontally and vertically. Randomize the words. Make it so that the words to choose from are not all related to the words that need to be connected. Make it harder. Make the first word connect to the last word by connecting the last letter of the first word to the first letter of the last word. Add daily challenges that are like Wordle and are unique for each day.

Expand It:

How did you rework Word Links into a daily challenge?
Add the ability to change the day for a different puzzle. Each daily challenge should have a normal mode and a challenge mode.
